# Quant Trading Portfolio Overview

This repository curates a set of production-ready research prototypes that highlight different aspects of quantitative trading workflows:

- **Market Microstructure:** The limit order book simulator demonstrates queue dynamics, best-price discovery, and market-impact analysis with rich analytics exports.
- **Statistical Arbitrage:** The pairs trading project walks through data ingestion, pair selection, spread modelling, and execution-aware backtesting.
- **Intraday Momentum:** Short-horizon signals, execution filters, and performance diagnostics aimed at discretionary overlay strategies.
- **Shared Utilities:** Common plotting, evaluation, and data helpers that keep research experiments reproducible across notebooks and scripts.

Each project folder contains runnable scripts and unit tests where applicable. See the root `README.md` for quick-start instructions and per-module overviews.
